# Security policy

## Reporting a vulnerability

Please report a vulnerability privately, through GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. Do not open a public issue or pull request for it.

Include what you found, how to reproduce it, and the version or commit you tested.

## Supported versions

The project is pre-release. Only the latest `0.x` release receives security fixes.

| Version | Supported |
|---|---|
| Latest `0.x` release | Yes |
| Any earlier release | No |
